# 8-Bit Mac OS X Aqua Icon Suite (`64x64` Pixel Art)

Designed to match the **Studio Py — Mac OS X Aqua (Jaguar/Tiger) × Brutalist 8-Bit** interface (`w03_functions_and_modules.py — Studio Py`), translating Aqua's "lickable" translucent blue gel buttons, gumdrop traffic lights, and brushed Platinum chrome into hard-edge `64x64` pixel art (`32x32` logical `2x` blocks, zero anti-aliasing, zero blur).
