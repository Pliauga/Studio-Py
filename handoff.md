## Atomic-age hardware pivot (committed in `bfd4c8d`, plus uncommitted work below)

The lesson page is no longer a flat dark-green page; a 3D monitor bezel is fixed to the
viewport and the lesson scrolls natively beneath it.

- **`src/lib/components/scene/Monitor.svelte`** — one extruded slab built from a `Shape` plus a
  hole `Path`, so the frame is genuinely solid. `DEPTH = 2.6` world units (a box, not a sheet),
  `bevelThickness = thickness * 0.45`, `bevelSize = thickness * 0.3`, `bevelSegments = 6`.
  Materials are real PBR maps, not procedural noise: `static/textures/Plastic013A_1K-JPG_{Color,NormalGL,Roughness}.jpg`
  from ambientCG, `normalScale={[1.4, 1.4]}`, base `color="#201c18"`, `roughness={1.0}`,
  `metalness={0.2}`, `clearcoat={0.5}`. Four corner screws are `CylinderGeometry` + `MeshStandardMaterial`
  (`metalness 1.0`, `roughness 0.3`) sitting proud of the front cap. Lighting: Ambient 0.1,
  `DirectionalLight [-5,5,5] intensity={2.6}` with a 2048 shadow map, white `RectAreaLight`
  intensity 2, green `RectAreaLight` 0.6, and a `PointLight` `#33ff00` inside the screen.
- **Why Plastic013A, not Metal032:** Metal032's colour map is blue steel grey (`#7c8893`); the
  Fallout references are olive-black. Plastic013A's normal map also carries far more surface
  detail (std 9.8 vs 1.0).
- **Post-processing** is a hand-built `postprocessing` composer (`alpha: true`, `multisampling: 4`)
  with `BloomEffect`, `ChromaticAberrationEffect`, `NoiseEffect`; Threlte's own render is switched
  off via `autoRender.set(false)` and the composer renders in `useTask`.
- **`.glass-layer`** in `src/routes/lesson/[slug]/+page.svelte` sits above the canvas and carries
  the scanlines, the inset vignette and the glare; the canvas stays transparent over the DOM.

## The layout trap this pivot created (read before touching padding)

The bezel is **recessed**, so its inner wall projects inwards in perspective. The visible screen
hole therefore starts well inside `--bezel-w`, which is only the *outer* frame width. Measured
against the rendered canvas (bezel-on screenshot diffed against bezel-off):

| viewport | real aperture x | `--bezel-w` |
|---|---|---|
| 1920 | 209 … 1711 | 72 |
| 1440 | 179 … 1261 | 72 |
| 1280 | 160 … 1120 | 64 |
| 1024 | 126 … 898 | 51 |
| 820 | 99 … 721 | 41 |
| 420 | 54 … 366 | 24 |

The aperture is ~12.5vw, i.e. ~2.5x the extruded thickness — never `--bezel-w`. The original
`padding: 12vh 10vw` gave a 144px inset at 1440, 35px short of the lip, which is what sliced the
first character off every heading ("VARIABLES" cut in half).

The fix, in `.lesson-content.crt`:

```css
--screen-inset: max(calc(var(--bezel-w) * 2.4), calc(12.5vw + 1rem));
padding: calc(var(--head-h) + var(--screen-inset)) var(--screen-inset);
```

The `+ 1rem` is the deliberate gap between glass edge and text. Supporting changes in the same
file: `.reader` capped at `max-width: 900px` inside the tube; the old
`@media (max-width: 700px) { padding-inline: 6vw }` override **removed** (a fixed vw padding falls
back inside the aperture on phones — it was the original bug in miniature); `.pager` collapses to
one column at 900px (source order matters — the media block must come *after* the base `.pager`
rule or it loses); the pixel-face sign-off button constrained with `max-width: 100%` and
`padding: 1.2rem clamp(0.6rem, 3vw, 2rem)`.
`src/lib/components/PyExercise.svelte` gains `flex-wrap: wrap` on `.toolbar`, because the console
column inside the bezel is too narrow for the nowrap shortcut label plus the action buttons.

pixels never render, so hiding them produces an identical diff either way. The test that works

horizontally scrollable `pre` as its own clipped box. Current result, all seven viewports:

  `static/textures/` is untracked (2.5 MB of binary assets — needs approval before it lands, per
  AGENTS.md's binary-file rule).

  scroll; that figure is not representative. The bezel's cost is a canvas composited under a
  fixed `backdrop-filter` layer — worth measuring on a real GPU before shipping.
- Earlier motion numbers still stand: cold cover ~345 ms (~25 ms over the 320 ms token), warm
  clicks within a few ms, warp recorded at 120 Hz (`.artifacts/r2b/warp-frames.json`).
